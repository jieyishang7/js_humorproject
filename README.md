# js_humorproject

Week 1: Hello World for The Humor Project. A simple responsive Next.js app.

## Run locally

```bash
npm ci
npm run dev
```

Open http://localhost:3000.

## Check and build

```bash
npm run lint
npm run build
npm start
```

## Deployment

Import `jieyishang7/js_humorproject` into Vercel, using the Next.js preset and the repository root. Disable Deployment Protection for public viewing, and submit the unique deployment URL associated with the submitted Git commit.

## IntelliJ

Use **Get from VCS** (or **File > New > Project from Version Control**) with `https://github.com/jieyishang7/js_humorproject.git` to clone this repository in IntelliJ.
